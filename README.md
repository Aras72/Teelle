# تیله (Teelle)

تیله یک پلتفرم فارسی برای رساندن خانواده از صفحه‌نمایش به بازی واقعی است. محصول شرایط همان لحظه را می‌فهمد و از کتابخانه کنترل‌شده و تأییدشده، سه بازی مناسب پیشنهاد می‌دهد.

> کودک، بیشتر از اسباب‌بازی به هم‌بازی نیاز دارد.

## وضعیت فعلی

- مرحله: بستن Implementation و Testing & QA روی Scope پیاده‌سازی‌شده
- فاز: `PHASE 14 CLOSURE + PHASE 15 — TESTING & QA`
- وضعیت Gate: `IN PROGRESS / NOT PASS`
- پشته قطعی وب: PHP + Laravel
- تحویل اصلی: وب‌سایت کامل و Responsive
- موبایل: فقط TWA و فقط پس از عبور از `WEBSITE COMPLETE GATE`

وضعیت دقیق و جاری در [PROJECT-STATUS.md](PROJECT-STATUS.md) ثبت می‌شود.

فازهای ۱۱ و ۱۲ کامل‌اند. فاز ۱۳ Promptهای 001 تا 010 را Freeze کرده، اما Prompt 011 هنوز LOCKED است؛ بنابراین فاز ۱۴ با وجود اجرای Promptهای 001 تا 010 کامل اعلام نمی‌شود. فاز ۱۵ برای QA همین Scope فعال است و Regression محلی MySQL 8.4.11 پاس شده، اما Release Gate تا تکمیل کنترل‌های باقی‌مانده باز می‌ماند.

## تصمیم‌های فنی قطعی

معماری TypeScript/Next.js/NestJS/React Native پیشنهادشده در Master Product Brief v1.0 دیگر تصمیم اجرایی پروژه نیست. طبق دستور جدید مالک و پروتکل مادر:

- زبان سمت سرور MUST برابر PHP باشد.
- فریم‌ورک وب MUST برابر Laravel باشد.
- مالک و کاربران عادی MUST برای استفاده یا مدیریت روزمره به Terminal وابسته نباشند.
- نسخه موبایل، در صورت قرارگرفتن در Scope، MUST با TWA و پس از تکمیل وب‌سایت ساخته شود.

جزئیات و اثر این تغییر در [DECISIONS.md](DECISIONS.md) ثبت شده است.

## هویت تجربه

Motion بخشی از هویت تیله است. صفحه نخست اکنون تیله طبیعی ویدئویی Loopشونده و Poster fallback مصوب را نمایش می‌دهد. تعامل سه‌بعدی DEC-003 طبق DEC-020 و DEC-026 تا تأمین Asset همسان و تأیید بصری تازه تعلیق شده و مدل مصنوعی فعال نیست.

مدل، Migration، Seeder، پنل محتوایی و Pilot Draft بازی‌ها ساخته شده‌اند؛ انتشار محتوا و پیشنهاد واقعی تا عبور Review، Coverage و Ranking Gate به‌صورت fail-closed قفل می‌ماند.
