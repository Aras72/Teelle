# تیله (Teelle)

تیله یک پلتفرم فارسی برای رساندن خانواده از صفحه‌نمایش به بازی واقعی است. محصول شرایط همان لحظه را می‌فهمد و از کتابخانه کنترل‌شده و تأییدشده، سه بازی مناسب پیشنهاد می‌دهد.

> کودک، بیشتر از اسباب‌بازی به هم‌بازی نیاز دارد.

## وضعیت فعلی

- مرحله: برنامه‌ریزی محصول
- فاز: `PHASE 09 — TECHNICAL ARCHITECTURE`
- پیاده‌سازی: `LOCKED`
- پشته قطعی وب: PHP + Laravel
- تحویل اصلی: وب‌سایت کامل و Responsive
- موبایل: فقط TWA و فقط پس از عبور از `WEBSITE COMPLETE GATE`

وضعیت دقیق و جاری در [PROJECT-STATUS.md](PROJECT-STATUS.md) ثبت می‌شود.

## منابع حقیقت

ترتیب اعتبار منابع پروژه:

1. آخرین دستور صریح مالک
2. تصمیم‌های `APPROVED` یا `FROZEN` در [DECISIONS.md](DECISIONS.md)
3. مستندات مصوب پروژه
4. رفتار فعلی پیاده‌سازی
5. مستندات Draft
6. تاریخچه گفتگو
7. فرضیات AI

نسخه اصلی سه سند ورودی در `docs/00-foundation/source-materials/` نگهداری می‌شود. از این پس نسخه Repository این فایل‌ها مرجع خواندن است، نه نسخه Downloads یا پیوست گفتگو.

## تصمیم‌های فنی قطعی

معماری TypeScript/Next.js/NestJS/React Native پیشنهادشده در Master Product Brief v1.0 دیگر تصمیم اجرایی پروژه نیست. طبق دستور جدید مالک و پروتکل مادر:

- زبان سمت سرور MUST برابر PHP باشد.
- فریم‌ورک وب MUST برابر Laravel باشد.
- مالک و کاربران عادی MUST برای استفاده یا مدیریت روزمره به Terminal وابسته نباشند.
- نسخه موبایل، در صورت قرارگرفتن در Scope، MUST با TWA و پس از تکمیل وب‌سایت ساخته شود.

جزئیات و اثر این تغییر در [DECISIONS.md](DECISIONS.md) ثبت شده است.

## هویت تجربه

Motion بخشی از هویت تیله است. صفحه نخست باید یک تیله شیشه‌ای بزرگ و زنده در مرکز Hero داشته باشد که به سمت نشانگر واکنش نشان دهد و کاربر بتواند آن را مستقیماً بچرخاند. UI/UX Gate پاس شده و معماری اجرای Real-time، fallback و Motion budget در PHASE 09 تعریف می‌شود؛ ساخت واقعی در Implementation انجام خواهد شد.
