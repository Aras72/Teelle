# گزارش Prompt 034 — چهار موقعیت روزمره نهایی

## تصمیم مالک

فهرست موقعیت‌های فعال به چهار مقدار ثابت محدود شد:

1. بین وعده‌های غذایی
2. بعد از غذا
3. بین کارهای روزمره
4. قبل از خواب

## دامنه اجرا

- فرم عمومی هشت‌مرحله‌ای پیشنهاد بازی و اعتبارسنجی پاسخ‌ها.
- جست‌وجوی تیله جیگری و Metadata بازی.
- فرم ساخت و ویرایش مدیر و ادمین، Import ساختاریافته و Excel.
- Seeder، مهاجرت داده و ماتریس Coverage با ۲۰ ترکیب فعال.
- تمپلیت رسمی Excel؛ متن انتخاب‌شده در همه سلول‌های کشویی مشکی است.

## حفاظت از داده قدیمی

موقعیت‌های قدیمی غیرفعال می‌شوند، اما هیچ رابطه‌ای از بازی‌های موجود حذف یا خودکار بازنویسی نمی‌شود. مدیر هنگام ویرایش بازی قدیمی باید یکی از چهار مقدار فعال را انتخاب کند.

## اعتبارسنجی

- MySQL 8.4.11 fresh migration + seed: PASS؛ چهار موقعیت فعال و ۲۰ سلول بحرانی Coverage.
- تست متمرکز Quick Match، مدیریت محتوا و جیگری: ۲۶ تست و ۲۴۳ assertion، همگی PASS.
- Regression کامل Laravel با `DB_SCHEMA_VALIDATION=true`: ۱۱۸ تست و ۱۰۶۹ assertion، همگی PASS و بدون Skip.
- Pint، کامپایل Blade، هشت تست JavaScript، Vite production build، Composer audit و pnpm production audit: PASS.
- فایل‌های Excel با Artifact Tool ویرایش و رندر شدند؛ سه ستون موقعیت فقط چهار مقدار نهایی را دارند، گزینه قدیمی باقی نمانده و رنگ متن سلول‌های تمام منوهای کشویی مشکی است.
- مرورگر واقعی: هر چهار گزینه در ترتیب مصوب در تم تیره و روشن دیده شدند و Console warning/error صفر بود.
