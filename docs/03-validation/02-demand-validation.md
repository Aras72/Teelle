## Current evidence

### Available signals

- Community evidence از Search overwhelm، خستگی Caregiver، نبود وسایل و نیاز به بازی کم‌Setup پشتیبانی می‌کند.
- Productهایی مانند Kidoc و Puffling پیام «یک فعالیت مناسب همین حالا، نه فهرست بلند» را استفاده می‌کنند.
- Vroom و BabySparks نشان می‌دهند فعالیت Parent-child و Personalization یک Category فعال جهانی است.

### What these signals do not prove

- تقاضای بازار ایران

- توانایی پرداخت برای Jigari
- Retention
- CAC یا Channel viability
- تناسب دوره ۳/۶/۱۲ ماهه

## Validation sequence

### DV-01 — Problem interviews

Goal: کشف رفتار و Pain واقعی.

Interview prompts:

- آخرین باری که نمی‌دانستید با کودک چه بازی کنید چه زمانی بود؟
- چه شرایطی داشتید و چه کردید؟
- چقدر طول کشید تا تصمیم بگیرید؟
- چه چیزی پیشنهادهای موجود را غیرقابل استفاده کرد؟
- آخرین بار چه زمانی به‌خاطر خستگی یا نبود ایده از Screen استفاده کردید؟
- چه اطلاعاتی برای اعتماد به یک بازی لازم دارید؟

Output: anonymized notes، coded themes، counter-evidence و frequency table.

Status: NOT RUN

### DV-02 — Persian search-demand study

Candidate query families:

- با بچه چی بازی کنیم
- بازی بدون وسیله
- بازی در خانه با کودک
- بازی برای روز بارانی
- بازی در ماشین برای کودک
- بازی قبل خواب
- سرگرمی کودک بدون موبایل
- بازی برای کودک پرانرژی
- بازی مادر و کودک / پدر و کودک

Required evidence: ابزار دارای Volume/Trend، Geography=Iran، تاریخ و Method ثبت‌شده.

Status: NOT RUN

### DV-03 — Message test

Variants:

- «چی بازی کنیم؟»
- «سه بازی مناسب همین لحظه»
- «از گوشی به بازی واقعی»

Measure: comprehension، relevance، click intent و mismatch reason.

Status: NOT RUN

### DV-04 — Concierge Quick Match

بدون ساخت Engine کامل، Context واقعی گرفته شود و سه بازی از یک مجموعه Reviewed کوچک به‌صورت دستی اما طبق Ruleهای ثبت‌شده انتخاب شود.

Measure:

- Time-to-result
- Selected/no-selection
- Started/not-started
- Reason for rejection
