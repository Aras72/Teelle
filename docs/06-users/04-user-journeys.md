# User Journeys - تیله

Status: APPROVED FOR DESIGN
Phase: 06 - USER MODEL

## Guest value journey

Discovery -> فهم Promise -> «چی بازی کنیم؟» -> Context کوتاه -> سه نتیجه -> Detail -> Start -> گوشی کنار -> Complete -> Feedback

Activation برابر Login نیست؛ اولین `started` معتبر Activation اصلی است.

## Account and retention journey

Guest value -> دعوت غیرمزاحم به حساب -> Signup -> Merge Session -> Saved/History -> بازگشت -> Jigari evaluation -> خرید -> Weekly Plan یا Multi-child -> Renewal

## No-result journey

Context -> کمتر از سه Survivor -> توضیح صادقانه -> نمایش Constraint امن و قابل تغییر -> اقدام صریح کاربر -> Match جدید

## Lifecycle mapping

- Discovery: Landing، Collection یا Search engine
- Evaluation: Promise، نمونه ارزش و اعتماد به Safety
- Signup: بعد از ارزش Core یا برای قابلیت مالکیتی
- Activation: Play Start
- Usage: Match، Detail و بازی واقعی
- Retention: History، Saved، Pending recovery و Weekly Plan
- Advocacy: اشتراک‌گذاری تجربه یا بازی، بدون افشای داده کودک
