# Proto-personas - تیله

Status: PROVISIONAL
Phase: 06 - USER MODEL

طبق پروتکل، Persona بدون پشتوانه تحقیق مستقیم نباید قطعی معرفی شود. این‌ها Proto-personaهای طراحی هستند و با داده تحقیق مالک یا مصاحبه آینده اصلاح می‌شوند.

## نیلوفر، والد کم‌انرژی

- Context: عصر، کودک بی‌قرار، زمان و حوصله کم
- Goal: یک انتخاب قابل اعتماد بدون خواندن فهرست طولانی
- Friction: سؤال زیاد، Login زودهنگام، پیشنهاد با وسایل ناموجود
- Success: سه گزینه روشن و Start سریع

## امیر، والد دغدغه‌مند رشد

- Context: می‌خواهد بداند چرا بازی برای سن و وضعیت مناسب است
- Goal: بازی معنادار بدون ادعای اغراق‌آمیز
- Friction: توصیه مبهم، Safety پنهان، زبان شبه‌پزشکی
- Success: دلیل تناسب و مهارت‌های درگیر با زبان ساده

## مهسا، مراقب موقت

- Context: اطلاعات کامل پروفایل کودک را ندارد
- Goal: راه‌اندازی بازی امن با حداقل سؤال
- Friction: فرم طولانی و اصطلاحات تخصصی
- Success: Guest flow و سؤال‌های Context محور

## خانواده دوکودکی

- Context: دو سن و محدودیت متفاوت
- Goal: بازی مشترک واقعی
- Friction: میانگین‌گیری سن یا ترجیح یک کودک
- Success: تقاطع Safety و Eligibility، یا no-result صادقانه
