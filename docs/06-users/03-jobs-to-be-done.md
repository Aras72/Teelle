# Jobs To Be Done - تیله

Status: APPROVED FOR DESIGN
Phase: 06 - USER MODEL

## انتخاب فوری

When کودک آماده تعامل است و من انرژی تصمیم‌گیری ندارم،
I want to شرایط همین لحظه را خیلی کوتاه بگویم،
So I can بازی واقعی را سریع شروع کنم.

## اعتماد

When سه پیشنهاد می‌بینم،
I want to بدانم چرا مناسب‌اند و چه وسایل و مراقبتی می‌خواهند،
So I can با اطمینان یکی را انتخاب کنم.

## چند کودک

When چند کودک با سن یا نیاز متفاوت کنار هم هستند،
I want to فقط بازی‌های سازگار با همه را ببینم،
So I can کسی را کنار نگذارم یا ریسک پنهان نسازم.

## بازگشت و برنامه‌ریزی

When دوباره برای بازی برمی‌گردم،
I want to تاریخچه و برنامه کوتاه متناسب با خانواده‌ام داشته باشم،
So I can هر بار از صفر تصمیم نگیرم.
