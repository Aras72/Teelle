# User Pain Points - تیله

Status: APPROVED FOR DESIGN
Phase: 06 - USER MODEL

| Journey moment | Pain | Design response |
|---|---|---|
| Discovery | محصول شبیه انبار محتوا دیده می‌شود | Promise روشن و CTA واحد |
| Context | فرم طولانی در لحظه کم‌انرژی | Progressive disclosure و سؤال حداقلی |
| Result | انتخاب زیاد و دلیل نامشخص | دقیقاً سه گزینه با دلیل تناسب |
| Preparation | وسایل ضروری دیر دیده می‌شوند | Required materials روی Card و Detail |
| Safety | هشدار پنهان یا ترساننده | هشدار کوتاه، عملی، رایگان و پیش از Start |
| Start | Login یا Upsell مانع بازی است | Guest Start و فروش خارج از مسیر Core |
| Return | کاربر فراموش می‌کند Session را ببندد | Pending recovery رضایت‌محور |
| Multi-child | میانگین سن و پیشنهاد ناسازگار | تقاطع همه محدودیت‌ها و no-result صادقانه |
| Accessibility | Motion یا RTL مانع فهم می‌شود | reduced-motion، Focus، Touch و Keyboard |
