# User Segments - تیله

Status: APPROVED FOR DESIGN
Phase: 06 - USER MODEL

## Primary

بزرگسال همراه کودک که در همان لحظه نیاز به یک بازی قابل اجرا دارد. Device، زمان و توجه محدود دارد و باید پیش از دیدن ارزش مجبور به Login نشود.

## Behavioral segments

- والد خسته اما مشتاق: کاهش تصمیم و شروع زیر ۶۰ ثانیه مهم‌ترین ارزش است.
- والد دغدغه‌مند رشد: Explanation و Skills را می‌خواهد، بدون ادعای پزشکی.
- والد ضد Screen: خروج سریع از صفحه و شروع بازی واقعی را ترجیح می‌دهد.
- مراقب موقت: Context کودک را کمتر می‌داند و به سؤال‌های کوتاه نیاز دارد.
- خانواده چندکودکی: به تقاطع سن، Safety و علایق نیاز دارد، نه میانگین‌گیری.
- والد برنامه‌ریز: History، Saved و Weekly Plan برایش ارزش Jigari دارد.

## Context segments

- خانه یا بیرون، فضای کوچک یا باز
- وقت خیلی کم، متوسط یا طولانی
- انرژی پایین یا بالا
- وسایل محدود یا آماده
- یک کودک یا چند کودک

## Exclusions

- کودک کاربر مستقیم محصول نیست؛ تجربه برای بزرگسال طراحی می‌شود.
- محصول درمان، تشخیص رشد، کلاس آنلاین یا شبکه اجتماعی کودک نیست.
