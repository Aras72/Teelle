# Owner Directives

Status: APPROVED
Recorded: 2026-09-03

این سند دستورهای صریح مالک را ثبت می‌کند و در تعارض با پیشنهادهای قدیمی بریف اولویت دارد.

## Technology

- `OWNER-TECH-001`: پروژه MUST با PHP و Laravel ساخته شود.
- `OWNER-TECH-002`: پیشنهاد TypeScript-first در Brief v1.0 تصمیم اجرایی نیست.

## Repository

- `OWNER-REPO-001`: GitHub Repository `https://github.com/Aras72/Teelle.git` MUST حافظه اصلی پروژه باشد.
- `OWNER-REPO-002`: سه فایل ورودی MUST داخل Repository نگهداری و از نسخه Repository خوانده شوند.
- `OWNER-REPO-003`: عملیات و تغییرات پروژه MUST با تاریخچه قابل ردیابی Git ثبت شوند.

## Brand and Motion

- `OWNER-BRAND-001`: تمام صفحات MUST از Animationهای دارای هویت تیله و عناصر Brand استفاده کنند.
- `OWNER-HOME-001`: صفحه اول MUST یک تیله بزرگ در مرکز داشته باشد.
- `OWNER-HOME-002`: تیله MUST حالت زنده و انیمیشنی داشته باشد.
- `OWNER-HOME-003`: تیله MUST نسبت به حرکت Mouse/Pointer به سمت نشانگر بچرخد.
- `OWNER-HOME-004`: کاربر MUST بتواند با تعامل مستقیم تیله را بگیرد و بچرخاند.

## Interpretation Boundaries

- Motion فراگیر به معنی شلوغ‌کردن همه صفحات با چندین تیله نیست؛ Brand Law «تیله همیشه زنده است، اما همه‌جا پر از تیله نیست» همچنان برقرار است.
- Interaction دقیق Mouse/Touch/Keyboard، Rendering technology و Performance budget در UI/UX و Architecture مشخص می‌شود.
- ثبت Requirement مجوز عبور از Planning Gates یا شروع زودهنگام Implementation نیست.
