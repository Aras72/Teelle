# Non-goals — تیله

Status: APPROVED
Phase: 04 — PRODUCT DEFINITION

## Product non-goals

- تبدیل تیله به بازی دیجیتال برای کودک
- بیشینه‌کردن Screen time یا Session duration
- ارائه Feed بی‌نهایت از ایده‌ها
- تبدیل‌شدن به رسانه عمومی فرزندپروری
- Marketplace خدمات یا اسباب‌بازی
- Social network، Chat یا UGC در MVP
- Gamification سنگین که بازی واقعی را به حاشیه ببرد

## Recommendation non-goals

- AI-generated games
- AI-selected یا AI-ranked recommendations
- AI rewrite دستور بازی در Runtime
- Sponsored recommendation یا Pay-to-rank
- Relax پنهانی Safety، Materials، Space یا Players rules
- نمایش بیش از سه Result برای پنهان‌کردن ضعف Matching

## Commercial non-goals

- Paywall کردن Safety
- فروش Recommendation بهتر
- Banner، Interstitial یا تبلیغ مزاحم
- Trial رایگان یا اشتراک یک‌ماهه در MVP
- تفاوت Feature میان دوره‌های ۳، ۶ و ۱۲ ماهه
- Fake urgency، Countdown یا Dark pattern

## Platform non-goals

- Next.js/NestJS به‌عنوان هسته اجرایی
- React Native، Flutter یا Native Android
- iOS app در MVP
- TWA پیش از Website Complete Gate
- Microservices یا Kubernetes بدون Requirement اثبات‌شده
- محصول موازی برای Mobile

## UX non-goals

- طراحی کودکانه صرفاً چون موضوع محصول کودک است
- استفاده تزئینی و بی‌دلیل از Animation
- پرکردن هر صفحه با چندین Marble بدون نقش
- قربانی‌کردن CTA، Accessibility یا Performance برای جلوه بصری
- درخواست اطلاعاتی که سیستم می‌تواند از قبل بفهمد

## Data and privacy non-goals

- جمع‌آوری نام خانوادگی، عکس یا جنسیت کودک در MVP
- استفاده از completed/rated در Heartbeat عمومی
- ذخیره داده بدون Purpose، Retention و Access rule
- اتصال مستقیم Web/TWA به Database بدون لایه Application

## Governance rule

افزودن هر Non-goal به Scope نیازمند Change Impact Analysis و Decision جدید است.
