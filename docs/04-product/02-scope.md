# Product Scope — تیله

Status: IN_REVIEW
Phase: 04 — PRODUCT DEFINITION

## MUST HAVE — Website MVP

- Landing و Homepage Hero با تیله تعاملی
- Quick Match مهمان
- Match Results با دقیقاً سه پیشنهاد و Explainability
- Game Detail و Start action
- Play Session، Complete و Rating
- no-result صادقانه بدون Relax پنهانی
- Auth، Onboarding و Home محدود
- Jigari entitlement و دوره‌های ۳/۶/۱۲ ماهه
- Child Profile برای Jigari
- Saved و History طبق Free/Paid boundary
- Search/Filter کامل برای Jigari
- Weekly Plan و Multi-child Matching برای Jigari
- Settings، About و Collections
- Admin Content CRUD، Import، Review/Publish و Audit
- Coverage Dashboard و Analytics/Reports
- Responsive RTL، Accessibility، Security، Privacy و Performance
- PWA readiness لازم برای سایت
- حداقل Library مصوب هر Release stage

## SHOULD HAVE

- Guest session merge پس از Registration
- Pending Session Recovery
- Reminder سبک و رضایت‌محور
- Export PDF و CSV/Excel برای Admin report
- SEO pages برای Game و Scenario/Collection
- Relationship-aware copy در Momentهای مهم

## COULD HAVE — after core evidence and capacity

- Caregiver sharing محدود با Privacy دقیق
- Personalization weight v2 بر اساس Preference و Rated history
- Segment-specific deterministic weights v3
- Collectionهای فصلی و فرهنگی بیشتر
- Experiment framework پیشرفته

## WON'T HAVE — MVP

- Chat
- UGC
- Social network مستقیم
- Marketplace
- Dark Mode
- iOS app
- Native Android، React Native یا Flutter
- TWA پیش از Website Complete
- AI Recommendation، AI Generation یا AI rewrite بازی
- Sponsored recommendation یا Pay-to-rank
- Banner، Interstitial یا تبلیغ مزاحم
- Gamification سنگین
- Infinite feed
- Notification spam، Fake urgency یا Countdown
- Safety پشت Paywall

## Scope boundary

Android در Brief v1.0 به‌عنوان MVP آمده بود، اما با `DEC-001` superseded است. Mobile delivery فقط TWA و فقط پس از تکمیل و تأیید وب‌سایت است؛ بنابراین جزو Website MVP نیست.

## Open scope decision

Age range دقیق بازی‌های Website MVP هنوز تعیین نشده و MUST پیش از Product Gate مشخص شود.
