# Solution Hypotheses — تیله

Status: APPROVED
Phase: 01 — IDEA DEVELOPMENT

این سند راه‌حل‌ها را مقایسه می‌کند. مصوب‌بودن جهت فعلی تیله به معنی Validate شدن تقاضای بازار نیست.

## H1 — Quick Match قطعی با سه پیشنهاد

Description: چند سؤال کوتاه درباره Situation گرفته شود و Rule Engine از کتابخانه Published/Reviewed دقیقاً سه بازی مناسب و متنوع ارائه کند.

User Value:

- کاهش هزینه ذهنی انتخاب
- تناسب با شرایط همین لحظه
- اعتماد بیشتر از طریق دلیل قابل توضیح

Advantages:

- هم‌راستا با Promise Core
- قابل تست و Explainable
- بدون ریسک AI-generated/AI-selected content
- Core رایگان می‌تواند Value Before Registration بسازد

Disadvantages:

- به Metadata کامل و Coverage قوی نیاز دارد
- No-result می‌تواند تجربه را متوقف کند
- کیفیت خروجی به Rules و Editorial work وابسته است

Complexity: MEDIUM تا HIGH؛ پیچیدگی اصلی در محتوا، Taxonomy، Safety و Coverage است نه در UI.

Monetization: Quick Match پایه رایگان؛ Personalization پیشرفته و قابلیت‌های مکمل در تیله جیگری.

Status: SELECTED PRODUCT DIRECTION; VALIDATION PENDING

## H2 — مرور کتابخانه با Search و Filter

Description: کاربر مستقیماً کتابخانه بازی‌ها را جست‌وجو و فیلتر کند.

User Value:

- کنترل بالا برای والد برنامه‌ریز
- کشف بازی برای موقعیت‌های آینده

Advantages:

- الگوی آشنا
- مفید برای کاربران High-intent
- پایه مناسب SEO و Collections

Disadvantages:

- اصطکاک تصمیم‌گیری را برای کاربر خسته بازتولید می‌کند
- می‌تواند به فهرست طولانی و Choice overload تبدیل شود
- به‌تنهایی Promise اصلی تیله را محقق نمی‌کند

Complexity: MEDIUM

Monetization: Search/Filter کامل قابلیت تیله جیگری است.

Status: SELECTED AS COMPLEMENTARY SOLUTION; NOT CORE ENTRY

## H3 — Weekly Plan شخصی‌سازی‌شده

Description: برای اعضای جیگری، برنامه هفتگی بازی با استفاده از Profile و History ساخته شود.

User Value:

- کاهش تصمیم‌گیری تکرارشونده
- کمک به والد برنامه‌ریز

Advantages:

- Retention loop بالقوه
- ارزش تکرارشونده برای Membership

Disadvantages:

- نیازمند History و Profile معتبر
- ممکن است با Situation لحظه‌ای ناسازگار شود
- قبل از اثبات Quick Match ریسک Scope expansion دارد

Complexity: HIGH

Monetization: Jigari-only

Status: MVP SUPPORTING FEATURE; DEPENDENT ON CORE VALIDATION

## H4 — محتوای سناریومحور برای ورود به Quick Match

Description: صفحات Scenario مانند روز بارانی، ماشین یا بدون وسیله کاربر را از Search/Social به Quick Match هدایت کنند.

User Value:

- شروع از زبان و موقعیت واقعی کاربر
- کاهش فاصله Discovery تا Action

Advantages:

- مناسب SEO و Social discovery
- هم‌راستا با واحد طراحی Situation

Disadvantages:

- محتوای زیاد بدون Conversion می‌تواند به رسانه‌ای جدا از محصول تبدیل شود
- نیازمند سنجش Attribution تا Play Start است

Complexity: MEDIUM

Monetization: Acquisition برای Core و Membership

Status: GO-TO-MARKET HYPOTHESIS; RESEARCH REQUIRED

## H5 — Chat یا AI Recommendation

Description: کاربر با AI گفتگو کند و AI بازی پیشنهاد یا تولید کند.

Advantages:

- ورودی انعطاف‌پذیر

Disadvantages:

- خروجی غیرقطعی و دشوار برای Safety review
- احتمال ساخت بازی یا ادعای نامعتبر
- تعارض مستقیم با قوانین مصوب محصول

Status: REJECTED / OUT OF SCOPE

## Direction

H1 راه‌حل Core است. H2، H3 و H4 تنها در صورتی ارزشمندند که H1 واقعاً Play Starts ایجاد کند. H5 ممنوع است.
