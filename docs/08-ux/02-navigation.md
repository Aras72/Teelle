# Navigation Model - تیله

Status: DRAFT FOR REVIEW
Phase: 08 - UI/UX DESIGN

## Desktop header

- Wordmark تیله
- «تیله جیگری»
- «درباره تیله»

ورود به پیشنهاد بازی از CTA اصلی «چی بازی کنیم؟» انجام می‌شود و فهرست یا مجموعه عمومی بازی‌ها در Navigation وجود ندارد؛ همه کاربران برای دریافت پیشنهاد باید مسیر سؤال‌های تطبیقی را طی کنند.
- Account action
- Primary CTA ثابت: «چی بازی کنیم؟»

Header یک‌خط، حداکثر ۷۲px و RTL است. CTA تکراری با Label دیگر ساخته نمی‌شود.

## Mobile

- Wordmark
- Primary CTA فشرده
- Menu button با Label دسترس‌پذیر
- Drawer شامل Navigation ثانویه و Account

Bottom navigation فقط برای محیط Authenticated و پس از آزمون کاربردپذیری بررسی می‌شود؛ در Guest Match استفاده نمی‌شود تا تمرکز مسیر حفظ شود.

## In-flow navigation

- Back رفتار مرورگر را حفظ می‌کند.
- Progress در Quick Match بر اساس سؤال‌های واقعی است، نه Stepهای تزئینی.
- Active Play فقط خروج ایمن و «برگشتیم» را برجسته می‌کند.
- Breadcrumb برای Admin و صفحات عمیق Content استفاده می‌شود، نه Home و Match.
