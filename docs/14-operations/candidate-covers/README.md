# کاورهای پیشنهادی بازی‌ها

تصویر هر بازی با شناسه همان بازی نام‌گذاری می‌شود؛ برای نمونه:

- `face-mirror.png`
- `cup-tower.jpg`
- `paper-bridge.webp`

فرمت‌های قابل استفاده `png`، `jpg`، `jpeg` و `webp` هستند. فایل اکسل فاز ۱۴ تصویر موجود در این پوشه را داخل ردیف همان بازی نشان می‌دهد. نبود فایل یعنی هنوز تصویری برای بررسی آماده نشده است.

تصویر پیشنهادی باید با مرجع سبک موجود در فایل اکسل هماهنگ باشد، نوشته داخل تصویر نداشته باشد و مالکیت یا مجوز استفاده از آن مشخص باشد.
