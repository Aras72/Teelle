# Data Security

Status: ACCEPTED BASELINE
Phase: 11 - SECURITY & PRIVACY

## Transport and storage

- HTTPS is mandatory with HSTS after domain validation.
- MySQL connection uses encrypted transport when the Pars Pack plan supports it؛ credentials are least-privilege and separate per Environment.
- Password/OTP secrets are hashed or one-way verified؛ payment credentials are never stored.
- Sensitive backup and Object storage are encrypted and access-controlled.

## Application controls

- All input uses Form Request/DTO allowlists، type bounds and normalized enums.
- Eloquent/Query Builder parameter binding is mandatory؛ user-controlled column names، raw ordering and raw SQL are prohibited.
- Blade escapes output by default. Raw HTML requires a documented sanitizer and test.
- CSRF protection covers cookie-authenticated mutations؛ Webhooks use provider signature instead of CSRF bypass without verification.
- CSP starts in report-only during Staging and becomes enforced before Production.
- Arbitrary server-side URL fetching is absent؛ integration endpoints are configuration allowlisted.

## File and import security

- Upload requires authenticated authorized staff.
- Extension، MIME and file signature are checked independently؛ size، dimensions and decompression limits apply.
- Filename/path is generated by the application، original name is metadata only and executable types are denied.
- Files enter quarantine outside executable webroot and become public only after scan/validation/review.
- CSV/Excel export neutralizes formula-leading cells.

## Secrets and logging

- Secrets stay in Pars Pack control panel/environment configuration، never Git، frontend bundle or error response.
- Logs use UTC، request ID and pseudonymous actor ID and exclude cookies، tokens، credentials، raw payment payload and child free text.
- Secret rotation and emergency revocation are part of the incident runbook.

## Database integrity

Foreign keys، unique idempotency keys and transactions protect Match/Play/Payment invariants. Application database user cannot create users or grant privileges. Production database is not reachable publicly unless provider architecture forces a controlled allowlist.
