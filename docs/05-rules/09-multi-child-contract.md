# Multi-child Compatibility Contract - تیله

Status: APPROVED BASELINE
Phase: 05 - PRODUCT RULES

Multi-child یک قابلیت Jigari است، اما کیفیت و Safety پیشنهاد آن خریدنی نیست.

## قواعد Eligibility

- هر کودک باید در زمان Match داخل `6 <= age_months < 156` باشد.
- بازه سنی بازی باید تمام کودکان شرکت‌کننده را پوشش دهد؛ میانگین سن ممنوع است.
- `minimum_players`، `maximum_players` و تعداد بزرگسالان حاضر باید با کل گروه سازگار باشند.
- تقاطع محدودیت‌های Safety همه کودکان و Context اعمال می‌شود؛ سخت‌گیرانه‌ترین محدودیت برنده است.
- Required materials، Location، Space و Duration برای کل گروه بررسی می‌شوند.
- History یا علاقه یک کودک نمی‌تواند ناسازگاری کودک دیگر را جبران کند.
- اگر سه بازی مشترک معتبر وجود نداشته باشد، پاسخ `no-result` است.
- تفکیک گروه به Matchهای جدا فقط با انتخاب صریح کاربر پیشنهاد می‌شود و خودکار نیست.

## Privacy

- نام نمایشی یا لقب برای تشخیص پروفایل کافی است؛ نام خانوادگی، عکس و جنسیت لازم نیست.
- خروجی دلیل تناسب را برای گروه توضیح می‌دهد و اطلاعات حساس یک کودک را برای دیگری آشکار نمی‌کند.

## مثال‌های قابل تست

1. کودکان ۲ و ۸ ساله، بازی با سقف ۶ سال: حذف می‌شود.
2. یکی از کودکان محدودیت Sensory دارد: بازی `sensory_intensity` حذف می‌شود.
3. بازی برای سه Player و گروه دو کودک با یک بزرگسال: سازگار است، اگر Metadata همان تعریف را تأیید کند.
4. دو Survivor مشترک: no-result، بدون افزودن بازی ناسازگار.
