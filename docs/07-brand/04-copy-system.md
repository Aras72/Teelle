# Copy System - تیله

Status: APPROVED
Phase: 07 - BRAND IDENTITY

## Core copy

- Core CTA: «چی بازی کنیم؟»
- Value proposition: «بازی مناسب، برای همین لحظه.»
- Tagline: «کودک، بیشتر از اسباب‌بازی به هم‌بازی نیاز دارد.»

## CTA rules

- یک Intent، یک Label ثابت.
- فعل کوتاه و مشخص: «شروع بازی»، «برگشتیم»، «دوباره پیشنهاد بده».
- CTA اصلی Home فقط «چی بازی کنیم؟» است.
- CTA فروش در مسیر Core مزاحم Start نمی‌شود.
- Tagline رسمی MUST در یک بخش مستقل و قابل دیدن روی Home نمایش داده شود: «کودک، بیشتر از اسباب‌بازی به هم‌بازی نیاز دارد.»
- Heartbeat pattern: «{PLAY_STARTS} بازی با تیله شروع شده»؛ مقدار از داده معتبر `started` می‌آید.

## Active Play and return

- Primary line: «گوشی را کنار بگذارید و با هم بازی کنید.»
- Return instruction: «وقتی تمام شد، برگردید و روی «بازی کردیم، برگشتیم» بزنید.»
- Completion CTA: «بازی کردیم، برگشتیم»
- این CTA همان رویداد `completed` را ثبت می‌کند؛ تغییر Label معنای Domain را تغییر نمی‌دهد.

## Error

الگو: چه شد + چه چیزی حفظ شد + قدم بعدی.

نمونه: «نتوانستیم سه بازی مناسب پیدا کنیم. محدودیت‌های ایمنی حفظ شدند. می‌توانی زمان یا وسایل در دسترس را تغییر بدهی.»

## Empty state

Empty state دلیل خالی‌بودن و یک اقدام مرتبط دارد، نه متن تزئینی.

نمونه: «هنوز بازی ذخیره نکردی. از سه پیشنهاد بعدی، هرکدام را خواستی نگه دار.»

## Onboarding

- فقط ارزش و Permission همان مرحله توضیح داده می‌شود.
- اطلاعات کودک با دلیل جمع‌آوری و حداقلی نگه داشته می‌شود.

## Notification

- Opt-in، قابل خاموش‌کردن و مرتبط با اقدام قبلی کاربر است.
- نمونه: «بازی‌تان هنوز باز است. اگر تمام شد، نتیجه را ثبت کن.»
